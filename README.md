# 🧩 Maze Solver App
An interactive maze solver built with Python and Streamlit that lets users create and solve mazes using Depth-First Search (DFS) and Breadth-First Search (BFS) algorithms.

🧱 Design the Maze
Users can mark:

Walls

Paths

A Starting Point

An Ending Point

🧠 Solve with DFS & BFS
Click "Find Path" to solve the maze using both DFS and BFS. The app will:

Display the path found by each algorithm

Show the number of states explored

Allow side-by-side comparison of both approaches

🎯 Goal
To visually compare how DFS and BFS behave in solving mazes and analyze their efficiency based on the number of explored states.
